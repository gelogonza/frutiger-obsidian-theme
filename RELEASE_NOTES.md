# Frutiger 0.2.2

- Adds a dedicated mobile layout instead of excluding mobile from the Frutiger glass treatment.
- Gives mobile notes, drawers, navigation bars, icons, callouts, tags, tasks, and inputs readable Aero and DORFic palettes.
- Uses larger touch targets and a more opaque single-pane surface for mobile readability.
- Adds reduced-transparency fallbacks for both mobile visual styles.

# Frutiger 0.2.1

- Improves DORFic contrast for completed tasks, tags, muted labels, links, headings, and tabs on copper glass surfaces.
- Gives Notebook Navigator's light porcelain panes a dedicated dark-text and dark-icon palette.
- Warms modal and menu surfaces while keeping their controls readable.
- Improves Aero contrast for completed tasks, muted labels, Reading View tags, Live Preview hashtags, and links on blue glass surfaces.
- Gives Aero's ice-white Notebook Navigator panes dedicated navy text, icons, selected states, and search controls.

# Frutiger 0.2.0

- Adds Style Settings support for visual style, wallpaper, glass density, blur, saturation, corner radius, tint, accent, and icon contrast.
- Adds Aqua Current, Glass Bubbles, and DORFic Daylight procedural wallpaper presets alongside the original Aero landscape.
- Adds a DORFic style with orange/red accents, white graphic lines, and a cleaner industrial-futurist treatment.
- Keeps wallpaper selection synchronized with Frutiger Liquid Glass 0.2.0 through shared body classes.

All wallpapers remain local and the new procedural presets add no network requests.

# Frutiger 0.1.0

First public release candidate of an original Frutiger Aero theme for Obsidian.

- Blue glass panels and a bundled sky-and-field landscape.
- Bright navigation controls and readable note text.
- Light and dark base-mode support.
- CSS-only appearance, with optional Frutiger Liquid Glass companion plugin for desktop WebGL2 effects.

The theme uses no network assets.
